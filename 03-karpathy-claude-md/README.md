A single `CLAUDE.md` file based on Andrej Karpathy's observations about how AI coding assistants go wrong.

## The 3 bad habits it targets
1. **Guessing** instead of asking when something is unclear
2. **Overbuilding**: 1,000 lines when 100 would do
3. **Side-effect edits**: changing code it doesn't fully understand

## The 4 rules (my summary)
| Rule | In plain words |
|---|---|
| Think before coding | State assumptions, ask when unsure, show trade-offs |
| Simplicity first | The minimum code that solves the problem |
| Surgical changes | Only touch what the task needs |
| Goal-driven execution | Define what "done" looks like and prove it, e.g. with tests |

## Setup (1 step)
1. Open [CLAUDE.md in the original repo](https://github.com/multica-ai/andrej-karpathy-skills/blob/main/CLAUDE.md), copy it into the **root of your project folder**, and keep the name `CLAUDE.md`.

Claude Code reads `CLAUDE.md` automatically at the start of every session. Already have one? Paste these rules at the top of yours.

## How I use it
- I keep the rules at the top of my project `CLAUDE.md`, then add my own project rules underneath.
- When the AI over-builds, I just say "simplicity first", and it knows exactly what I mean.
